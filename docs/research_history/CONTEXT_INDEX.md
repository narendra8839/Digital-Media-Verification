# Digital Media Verification — Context Files

Use these files as the project context set.

| File | Purpose |
|---|---|
| `DESIGN.md` | Frontend visual/design source supplied by the project owner |
| `PROJECT_CONTEXT.md` | Project purpose, scope, responsible-AI framing, constraints |
| `ARCHITECTURE.md` | Current/target technical architecture and modality flows |
| `DEVELOPMENT_RULES.md` | Git safety and implementation rules |
| `docs/TRAINING_AND_EVALUATION.md` | Full-data training, splits, GPU verification, metrics |
| `docs/DEMO_CONTEXT.md` | Final demo flow and presentation expectations |

## Important

`DESIGN.md` is **frontend design/context only**. It is not the system architecture document.

For implementation work, read:

1. `PROJECT_CONTEXT.md`
2. `ARCHITECTURE.md`
3. `DEVELOPMENT_RULES.md`
4. the relevant `docs/*.md`
5. `DESIGN.md` before frontend changes
